# iTranslate


An iOS application that converts speech to text and translates it into different languages.

## Features

* **Speech-to-Text:** Real-time audio capture and transcription.
* **Language Translation:** Translates transcribed text into target languages.
* **Native iOS Interface:** Built using Xcode (`iTranslate.xcodeproj`).

## Requirements

* iOS [26.0+]
* Xcode [Xcode Version, 26.0+]

## Installation

1. Clone the repository locally:
   ```bash
   git clone git@github.com:ilanchezhiank/iTranslate.git
   ```
2. Open `iTranslate.xcodeproj` in Xcode.
3. Configure any required API keys or permissions (e.g., `NSMicrophoneUsageDescription` and `NSSpeechRecognitionUsageDescription` in `Info.plist`).
4. Build and run the project on a simulator or physical iOS device.

## Usage

1. Launch the app and grant microphone and speech recognition permissions.
2. Select your source and target languages.
3. Tap the record button, speak clearly, and view the live transcription and translation.
